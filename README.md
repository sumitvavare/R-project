# R-project

Interactive Shri Rama quiz website with a timed challenge and ranked leaderboard.

## Features
- Player name entry before the quiz starts.
- 10 Shri Rama / Ramayana multiple-choice questions.
- Previous/Next navigation with answer validation.
- Live timer and final score summary.
- Leaderboard stored in browser `localStorage`.
- Ranking logic: higher score first, then lower time.

## Run
Open `index.html` in any modern browser.
